## ✨ Features

- 🤖 **AI-Powered Analysis** — Uses Groq's LLM to detect data quality issues
- 🧹 **Automatic Cleaning** — Fixes duplicates, missing values, and formatting issues
- 📅 **Date Normalization** — Standardizes inconsistent date formats
- 🎯 **Outlier Detection** — Identifies and caps suspicious values
- 📊 **Before/After Comparison** — See exactly what changed
- 💰 **Savings Calculator** — Estimates time and money saved
- 📥 **CSV Export** — Download your cleaned dataset
